# Formal Languages Python Project

This folder contains a small Python 3 project for a formal languages assignment.

## Files

- `grammar.py`: defines the `Grammar` class for right-linear grammars.
- `finite_automaton.py`: defines the `FiniteAutomaton` class (NFA/DFA behavior).
- `main.py`: demo script that builds a grammar, converts it to an automaton, and runs tests.

## Requirements

- Python 3.x
- No external libraries are required.

## How to run

1. Open a terminal in this folder.
2. Run:

```bash
python main.py
```

## What the demo shows

- Printed grammar and automaton structures.
- Random strings generated by grammar derivations.
- Acceptance checks for sample input strings.
- NFA to DFA conversion and determinism checks.
